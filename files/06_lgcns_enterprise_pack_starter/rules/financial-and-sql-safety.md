trigger: always_on
description: 정산·결제 수치 연산 및 SQL 쿼리 작성 시 필수 무결성·보안 표준
---

- 금액·수수료·세금·환율 연산에는 `float`를 절대 사용하지 않고 반드시 `Decimal(..., ROUND_HALF_UP)` 또는 정수 최소 통화 단위(`int`)만 사용한다.
- 모든 SQL 조회·변경 쿼리는 파라미터 바인딩(`?` 또는 `:name`)만 사용하며 문자열 포맷팅(`f"..."`, `%`, `.format`) 결합을 금지한다.
- 상태 변경 함수(출금·환불·재시도)에는 동시성 락(`Lock`/트랜잭션)과 `idempotency_key` 중복 방지 및 음수/0 입력 방어를 필수 포함한다.
- 패치 완료 보고 전 반드시 멀티스레드 경쟁 테스트, 빈 배열(`0건`) 경계값 테스트, 특수문자(`O'Connor`) 회귀 테스트를 실행해 통과를 확인한다.
